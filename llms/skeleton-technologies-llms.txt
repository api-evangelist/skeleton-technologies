# Skeleton Technologies

> Estonian-German manufacturer of high-power supercapacitor and SuperBattery energy storage
> systems built on patented Curved Graphene, sold as physical hardware to AI data center, grid,
> defense, automotive and heavy-transport customers. Founded 2009 in Tartu, Estonia. Produces at
> the Leipzig Superfactory (Germany), Varkaus (Finland) and Bitterfeld-Wolfen (Germany).

Generated by API Evangelist from the company's public website on 2026-08-28. Skeleton Technologies
does not publish an llms.txt of its own; this is a third-party index, not a company document.

## API surface

Skeleton Technologies publishes **no public API**. As of 2026-08-28 there is no developer portal,
no API reference, no OpenAPI/AsyncAPI/GraphQL contract, no SDK, no MCP server and no A2A agent
card on any host the company operates. Probes of `www.skeletontech.com` for `/openapi.json`,
`/apis.json`, `/llms.txt` and every `/.well-known/*` discovery path returned HTTP 404, and the
subdomains `api.`, `developer.`, `docs.`, `developers.`, `portal.`, `app.`, `cloud.`, `data.` and
`insight.skeletontech.com` do not resolve in DNS. The product is power hardware; the only software
is embedded battery/supercapacitor management firmware shipped inside the units.
